## O que é nosso projeto? 

O projeto consiste em fazer uma pipeline de dados desde o inicio, desde a geração dos dados
que serão populados no banco até os dados que serão utilizados para a analise dos dados dentro de
uma ferramenta própria para efetuar a análise dos dados que foram entregues pela camada gold.
